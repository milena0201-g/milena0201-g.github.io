# Portafolio de Milena Guevara

Este repositorio contiene el portafolio web personal de **Milena Guevara**, estudiante de Diseño Gráfico Digital. La página está desarrollada como un sitio web de una sola página, con estilo oscuro, acentos en teal y una presentación moderna orientada a mostrar sus habilidades, formación y trabajos.

## Descripción del proyecto

El objetivo del sitio es presentar a Milena como diseñadora gráfica con un perfil creativo, profesional y en formación. La web incluye:

- Hero section con presentación principal
- Sección Sobre mí basada en el texto real del CV
- Habilidades técnicas y blandas
- Formación académica
- Galería de trabajos recientes con filtro
- Sección de idiomas
- Formulario de contacto
- Footer con redes sociales y copyright

El diseño se basa en una referencia visual oscura con elementos planos y una identidad teal, adaptada al perfil real de Milena y mejorando legibilidad, contraste y responsividad.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts
- Lucide Icons
- SVG como recursos gráficos base

## Elementos EDITABLES

Se han dejado marcados con comentarios y placeholders los puntos que aún no están confirmados, como:

- redes sociales
- archivos de proyecto
- imágenes de trabajos
- CV descargable
- endpoint del formulario de contacto

Esto permite que el proyecto siga funcionando sin romper el layout y que luego se reemplacen los contenidos reales sin cambiar la estructura principal.

## Cómo ejecutar

Puedes abrir directamente el archivo `index.html` en el navegador o servir el proyecto localmente con un servidor estático, por ejemplo:

```bash
python -m http.server 8000
```

Luego accede a:

```text
http://localhost:8000
```
